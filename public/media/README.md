# 자료 이미지 넣는 곳

각 케이스 스터디의 아키텍처 다이어그램, 화면 설계, 발표 자료, 현장 사진을
여기에 넣습니다. 지금은 사이트에 빈 프레임이 그려져 있고,
파일을 넣고 경로만 연결하면 그 자리에 바로 들어갑니다. 레이아웃은 변하지 않습니다.

## 넣는 방법

1. 이미지를 아래 폴더 중 맞는 곳에 넣습니다.

```
public/media/interview-ops/     01 면접 운영 시스템
public/media/healthcare-ops/    02 헬스케어 체험관
public/media/edge-ai/           03 엣지 AI 프로젝트
```

2. `src/content/profile.ts` 에서 해당 케이스의 `media` 배열을 찾아
   주석 처리된 `src` 줄의 주석을 풀고 파일명을 맞춥니다.

```ts
{
  kind: '아키텍처',
  ratio: 'wide',
  caption: '지원 접수 → 서류 심사 → 면접 배정 → 점수 산정 전체 흐름도',
  src: '/media/interview-ops/architecture.png',   // ← 주석을 풀고 파일명 확인
  alt: '면접 운영 시스템 전체 흐름도. 지원 접수부터 점수 산정까지 4단계.',
},
```

`alt` 는 화면을 못 보는 사람에게 읽히는 설명입니다. 캡션과 같아도 되지만,
다이어그램이라면 무엇을 나타낸 그림인지 한 문장으로 적어주는 편이 낫습니다.

## 권장 규격

| 항목 | 권장값 |
|---|---|
| 형식 | 다이어그램·문서는 PNG, 사진은 JPG (또는 WebP) |
| 가로폭 | 1600px 이상 2400px 이하 |
| 용량 | 한 장당 500KB 이하 |
| 배경 | 어두운 사이트라 흰 배경 이미지는 눈에 튑니다. 여백을 회색조로 깔거나 WebP 투명 배경 권장 |

`ratio` 는 프레임 비율입니다. 자료 모양에 맞춰 고르세요.

- `wide` (16:7) — 가로로 긴 흐름도, 아키텍처
- `video` (16:9) — 대시보드, 발표 슬라이드
- `square` (1:1) — 현장 사진
- `portrait` (3:4) — 모바일 앱 화면

## PPT를 이미지로 뽑을 때

슬라이드 전체를 한 장씩 넣기보다, **핵심 1~2장만** 고르는 편이 낫습니다.
읽는 사람은 발표를 다시 듣는 게 아니라 결과를 확인하러 온 것이라서요.
