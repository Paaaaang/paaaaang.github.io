# 프로필 사진 넣는 곳

첫 화면에 들어갈 이력서 사진 자리입니다.
파일을 넣기 전까지는 같은 크기의 빈 프레임이 그려지므로, 넣어도 레이아웃이 움직이지 않습니다.

## 넣는 방법

1. 사진을 이 폴더에 넣습니다. 예: `public/media/profile/pioh.jpg`
2. `src/content/profile.ts` 에서 경로를 채웁니다.

```ts
photo: '/media/profile/pioh.jpg',
photoAlt: '서비스 기획자 오평일',
```

## 권장 규격

| 항목 | 권장값 |
|---|---|
| 비율 | 4:5 세로 (증명사진 그대로 넣어도 자동으로 잘립니다) |
| 크기 | 세로 1200px 이상 |
| 용량 | 500KB 이하 (JPG 품질 80 정도) |
| 형식 | JPG. 배경을 지운 경우 투명 PNG 또는 WebP |

## 사진이 화면에 어떻게 처리되는지

이력서 사진은 대부분 증명사진입니다. 균일한 회색·하늘색 배경에 정면 상반신이라,
어두운 화면에 그대로 얹으면 **문서 스캔본을 붙여넣은 것처럼** 보입니다.
그래서 코드에서 네 가지를 자동으로 처리합니다.

1. **크롭** — 4:5로 자르고 얼굴을 화면 위쪽 1/3에 둡니다 (`object-position: center 28%`).
   정중앙 배치는 증명사진 특유의 경직된 느낌을 그대로 가져옵니다.
2. **색 정합** — 채도를 조금 낮추고(0.88) 명암을 살짝 올려(1.06) 사이트 톤에 맞춥니다.
   완전 흑백으로는 만들지 않습니다. 채용 포트폴리오에서 흑백 인물 사진은 거리감을 만듭니다.
3. **경계 융합** — 프레임 안쪽에 비네트를 겹쳐 사각형이 배경 위에 떠 있지 않게 합니다.
4. **등장** — 아래에서 위로 640ms 마스크 리빌. 모션 축소 설정에서는 즉시 표시됩니다.

## 더 좋게 만들려면 (선택)

- **배경이 어두운 버전**으로 다시 촬영하거나 뽑으면 가장 잘 맞습니다.
- 배경 제거 후 투명 PNG로 저장하면 사이트 배경과 완전히 이어집니다.
- 정장 정면 증명사진보다 **반측면·자연광** 사진이 이 레이아웃에서 훨씬 잘 붙습니다.
- 위 셋 중 아무것도 못 하더라도 **원본 증명사진 그대로 넣으면 됩니다.**
  위 1~3번 처리가 어느 정도 메웁니다.

## 링크 공유용 이미지 (선택)

카카오톡·슬랙 등에 링크를 붙였을 때 뜨는 미리보기 이미지입니다.

- 파일명: `og.jpg`
- 크기: 1200 × 630px (가로형)
- `index.html` 의 `og:image` 가 이미 이 경로를 가리키고 있습니다.
