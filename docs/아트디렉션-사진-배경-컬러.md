요청하신 Behance(`behance.net/galleries/ui-ux`)는 **이 작업 환경의 네트워크 정책에서 차단**되어
직접 열어보지 못했습니다. `gaspar.framer.website`(에디토리얼 포트폴리오 레퍼런스)도 같은 이유로 막혔습니다.
보지 않은 것을 봤다고 쓰지 않기 위해 밝혀 둡니다.

대신 1차에서 설치한 스킬 안에 들어 있는 **레퍼런스 자료를 실제로 읽고** 기준을 잡았습니다.

## 1. 사진 — 증명사진을 에디토리얼 화면에 앉히기

### 문제

이력서 사진은 대부분 **증명사진**입니다. 균일한 회색·하늘색 배경, 정면 상반신, 중앙 정렬.
이걸 어두운 에디토리얼 화면에 그대로 얹으면 **문서 스캔본을 붙여넣은 것처럼** 보입니다.
`no-ai-design-slop` 기준으로 전형적인 실패 사례입니다. 주변과 재질이 전혀 맞지 않기 때문입니다.

동시에 반대 극단도 안 됩니다. 스킬 §2는 명확합니다:
*"Use photographs for every avatar. Never ship initials, illustrated heads, faceless silhouettes."*
이니셜 원이나 실루엣으로 대체하는 것은 선택지가 아닙니다.

### 처리 방식 (4단계)

**① 비율과 크롭 — 4:5 세로**
증명사진의 1:1.3 비율을 4:5로 잘라 인물을 화면 상단 1/3 지점에 둡니다.
`object-position: center 28%` 로 얼굴이 정중앙이 아니라 위쪽에 놓이게 합니다.
정중앙 배치는 증명사진 특유의 경직됨을 그대로 가져옵니다.

**② 색 정합 — 눌러서 맞추되 사람을 차갑게 만들지 않기**
완전 흑백 변환은 쓰지 않습니다. 채용 포트폴리오에서 흑백 인물은 거리감을 만듭니다.
대신 채도를 조금만 낮추고(`saturate(0.88)`) 명암을 살짝 올려(`contrast(1.06)`)
사이트의 잉크 톤과 같은 계조에 들어오게 합니다.

**③ 경계 융합 — 사각형이 떠 있지 않게**
증명사진의 균일한 배경은 테두리가 칼같이 드러납니다.
프레임 안쪽에 잉크 색으로 향하는 비네트를 겹쳐 아래쪽·가장자리를 배경에 녹입니다.
`inset shadow` 가 아니라 `::after` 레이어의 radial-gradient 로 처리해 이미지 자체는 건드리지 않습니다.

**④ 등장 — 마스크 리빌 640ms**
레퍼런스의 *"Reveal with a 500–760ms mask or shallow translate"* 를 따릅니다.
`clip-path: inset(...)` 로 아래에서 위로 걷어냅니다. 페이드인보다 의도가 분명하고,
"이 사람이 등장한다"는 느낌을 만듭니다. 모션 축소 설정에서는 완성 상태로 즉시 표시합니다.

### 사진 준비 가이드 (사용자 작업)

`public/media/profile/README.md` 에 따로 적어 둡니다. 요약하면:

- 가능하면 **배경이 어두운 버전**으로 다시 뽑거나, 배경 제거 후 투명 PNG로 저장
- 그게 어려우면 원본 그대로 넣어도 됩니다. 위 ②③ 처리가 어느 정도 메웁니다
- 세로 1200px 이상, 500KB 이하
- OG 공유용 1200×630 버전(`og.jpg`)을 따로 두면 링크 미리보기에도 얼굴이 뜹니다

## 2. 배경 — 평평한 검정을 종이로 바꾸기

### 문제

현재 배경은 `#0A0A0B` 단색 + 3D 파티클입니다.
파티클이 옅어지는 구간(문서 22% 이후)부터 화면이 **아무 재질 없는 순수 검정**이 됩니다.
이것이 "기본값으로 만든 다크 테마"처럼 보이는 가장 큰 이유입니다.

### 3층 구조로 재구성

```
 ┌ 3층 · 필름 그레인    SVG turbulence, opacity .04, 고정, 애니메이션 없음
 ├ 2층 · 챕터 색 워시   현재 챕터 색의 초저농도 radial, 스크롤에 따라 색만 교체
 ├ 1층 · 3D 파티클      히어로에서 정렬 연출, 이후 0.22로 후퇴 (기존)
 └ 0층 · 잉크 바탕      #0A0A0B
```

- **필름 그레인**: 인쇄물 질감. 이미지 파일 없이 인라인 SVG `feTurbulence` 로 만들어
  네트워크 요청 0건. 정적이라 GPU 비용도 없습니다. 움직이는 그레인은 멀미를 유발하므로 쓰지 않습니다.
- **챕터 색 워시**: 에디토리얼 레퍼런스의 *"introduce one muted color field per project"* 를
  어두운 화면에 맞게 번역한 것입니다. 색 패널을 통째로 까는 대신 3~5% 농도의 넓은 radial 로
  깔아 챕터가 바뀌었다는 것만 체감되게 합니다. 본문 대비는 건드리지 않습니다.
- **비네트**: 화면 가장자리를 아주 약하게 눌러 시선을 가운데로 모읍니다.

## 3. 컬러 — 측정해서 확정

감으로 고르지 않고 **잉크 배경 대비 WCAG 대비비를 계산**했습니다.
본문 크기 텍스트는 AA 기준 4.5:1, 큰 글자는 3:1이 최소선입니다.

| 토큰 | 값 | 잉크 대비 | 판정 |
|---|---|---|---|
| paper | `#E9E5DD` | 15.75 | 통과 |
| paper-dim | `#A8A49C` | 7.97 | 통과 |
| **paper-faint (기존)** | `#6D6A64` | **3.67** | **미달 — 결함** |
| **paper-faint (수정)** | `#85817A` | **5.11** | 통과 |
| ch1 버밀리언 | `#E8542F` | 5.41 | 통과 |
| ch2 틸 | `#3E8E7E` | 5.07 | 통과 |
| **ch3 인디고 (기존)** | `#5B6EE8` | 4.56 | 수치는 통과, **다른 이유로 교체** |
| **ch3 오커 (수정)** | `#C98A2B` | 6.74 | 통과 |

### 수정 ① paper-faint — 접근성 결함

`#6D6A64` 는 대비 3.67로 **본문 크기 텍스트 AA 기준에 미달**합니다.
그런데 이 색을 캡션, 출처 표기, 모노 라벨 등 **12~13px 작은 글자에 쓰고 있었습니다.**
가장 작은 글자에 가장 낮은 대비를 준 셈이라 실제 결함입니다. `#85817A`(5.11)로 올립니다.

### 수정 ② ch3 인디고 → 오커

`#5B6EE8` 는 대비는 통과하지만 교체합니다. 파랑·보라 계열은
`no-ai-design-slop` 이 지목하는 **"아무 제품에나 붙여도 어울리는 기본값"** 의 대표 색입니다.
앞의 두 챕터(버밀리언·틸)와 달리 이 색만 "그냥 골라진" 티가 납니다.

오커 `#C98A2B` 로 바꿉니다. 근거는 두 가지입니다.
하나는 대비가 6.74로 더 안전하다는 것, 다른 하나는 **03 챕터의 내용이 화재 관제와 경고 신호**라
계열이 맞는다는 것입니다. 색이 내용을 거들게 됩니다.

### 최종 팔레트

```
잉크   #0A0A0B   바탕
융기   #121214   카드·프레임 안쪽
선     #26262A   하어라인
종이   #E9E5DD   본문
흐림   #A8A49C   보조 본문
옅음   #85817A   캡션·라벨   ← 수정됨
──────────────────────────
01     #E8542F   버밀리언   면접 운영
02     #3E8E7E   틸        체험관 운영
03     #C98A2B   오커       엣지 AI   ← 수정됨
```

한 화면에 강조색은 **하나만** 씁니다. 세 색이 동시에 보이면 챕터 구분이 무의미해집니다.

## 5. 검증 기준

- 모든 본문 텍스트가 잉크 배경 대비 4.5:1 이상
- 챕터 전환 시 배경 색 워시가 바뀌되 본문 대비는 유지
- `prefers-reduced-motion` 에서 그레인 정적, 마스크 리빌 없음, 전체 내용 즉시 표시
- 사진 미첨부 상태에서도 레이아웃이 동일
