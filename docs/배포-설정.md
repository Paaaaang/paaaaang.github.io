# 배포 설정 — 직접 해야 하는 것

/ 은 GitHub 레포 설정을 바꿀 권한이 없습니다.
아래 세 가지는 직접 하셔야 합니다. 전부 합쳐 3분쯤 걸립니다.

---

## 1. 레포 이름 변경 (선택이지만 권장)

**제가 못 합니다.** 시도해봤고, 다음과 같이 거부됩니다.

```
HTTP 403
{"message":"Repository settings writes are not permitted through this proxy."}
```

레포 설정 쓰기는 이 작업 환경에서 차단돼 있습니다. 직접 하셔야 합니다.

### 방법

1. https://github.com/Paaaaang/pioh.github.io/settings 접속
2. 맨 위 **Repository name** 칸의 `pioh.github.io` 를 `Paaaaang.github.io` 로 변경
3. **Rename** 클릭

### 바뀌는 것

| | 변경 전 | 변경 후 |
|---|---|---|
| 사이트 주소 | `paaaaang.github.io/pioh.github.io/` | `paaaaang.github.io/` |
| 레포 주소 | `github.com/Paaaaang/pioh.github.io` | `github.com/Paaaaang/Paaaaang.github.io` |

옛 주소는 GitHub 이 자동으로 새 주소로 리다이렉트합니다. 링크가 깨지지 않습니다.
로컬에 클론해둔 것이 있다면 remote 만 고치면 됩니다.

```bash
git remote set-url origin https://github.com/Paaaaang/Paaaaang.github.io.git
```

### 이름을 안 바꾸겠다면

`.github/workflows/deploy.yml` 의 `VITE_BASE` 를 `/` 에서 `/pioh.github.io/` 로 바꾸세요.
그 한 줄만 고치면 하위 경로에서도 정상 동작합니다.

---

## 2. GitHub Pages 켜기 (필수)

현재 이 레포는 **Pages 가 꺼져 있습니다** (`has_pages: false`).
켜지 않으면 워크플로가 빌드에 성공해도 배포 단계에서 실패합니다.

1. Settings → 왼쪽 메뉴 **Pages**
2. **Source** 를 `Deploy from a branch` 가 아니라 **`GitHub Actions`** 로 변경

---

## 3. 기본 브랜치 정리 (필수)

현재 이 레포의 **기본 브랜치가 `claude/awesome-cerf-tklmiu`** 입니다.
빈 레포에 이 브랜치를 처음 푸시해서 GitHub 이 그걸 기본값으로 잡았습니다.

지금은 워크플로가 `main` 과 이 브랜치 **양쪽 모두**에서 돌도록 해뒀기 때문에
당장 배포는 됩니다. 다만 작업 브랜치가 기본 브랜치인 상태는 정상이 아닙니다.

### 정리 방법

```bash
git checkout -b main claude/awesome-cerf-tklmiu
git push -u origin main
```

그다음 Settings → General → Default branch 에서 **`main`** 으로 변경하고,
`.github/workflows/deploy.yml` 의 트리거에서 `claude/awesome-cerf-tklmiu` 줄을 지우세요.
